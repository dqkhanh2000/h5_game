# Flappy Bird Canvas Game

Beginner-friendly Flappy Bird game made with HTML5 Canvas 2D.

Open `index.html` in a browser, then press Space, click, or tap to flap.

## File structure

- `index.html` creates the canvas and loads scripts.
- `style.css` centers the game on the page.
- `game_object.js` has the shared position and movement code.
- `bird.js` controls bird physics and drawing.
- `pipe.js` controls pipe movement, drawing, and collision.
- `game_ui.js` draws the score and messages.
- `game.js` connects everything with input, update, draw, and restart logic.
